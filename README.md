## VPN Gate

项目地址：

https://www.vpngate.net/

### 项目状态

- 日本筑波大学学术项目
- 已持续运行多年
- 全球志愿者共享服务器

### 实测结果

⚠️ 偶尔可用

问题：

- 速度波动极大
- 延迟较高
- 中国大陆连接成功率不稳定
对 VPN Gate 来说，它作为学术项目和免费志愿者服务，有一些比较明显的缺点，我帮你整理如下（以 2026 年中国大陆环境实测为参考）：

1. 稳定性差
节点随时上下线：因为完全依赖全球志愿者，节点不可控。
高峰时段几乎不可用：热门节点往往同时被大量用户占用，速度下降明显。
连接成功率低：在防火墙严格的环境下，有时节点能 ping 通但无法成功建立 VPN 连接。
2. 速度慢，延迟高
节点多为普通家庭或小型服务器，带宽有限。
由于分布全球，尤其是亚洲到欧美节点，延迟可能在 150–400ms 甚至更高。
下载、视频或大流量传输体验差。
3. 节点安全和隐私不可控
节点是志愿者提供的中继服务器，理论上运营者可能监控流量。
不建议用于敏感账户登录、金融交易等场景。
数据加密安全性依赖 VPN 协议本身（OpenVPN/IPSec/L2TP），节点本身不受项目保证。
4. 使用体验不友好
官方网站需要手动选择节点并下载配置文件。
节点经常变动，需要频繁刷新和导入客户端。
没有统一管理面板或客户端自动更新功能。
5. 易受封锁
在中国大陆、部分企业网络环境中，VPN Gate 节点经常被防火墙屏蔽。
TCP/UDP 隧道端口容易被识别并阻断。
实测可用节点数量通常很少，短期内可能全部失效。

# 2026年的现实情况

经过近几年持续封锁后：

## 免费公开节点

现状：

- 存活时间越来越短
- 被共享后迅速失效
- GitHub节点池大量依赖互相搬运

常见现象：

- README显示更新
- Clash成功订阅
- 实际测速全部超时

即：

"有链接 ≠ 有节点"

"有节点 ≠ 能连接"

---

## Clash Verge 和 v2rayN 本身没有问题

很多用户误以为：

- Clash Verge失效了
- v2rayN失效了

- 节点被封
