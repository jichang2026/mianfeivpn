## Pawdroid Free-servers

项目地址：

https://github.com/Pawdroid/Free-servers

### 项目状态

- GitHub仓库仍在更新
- Star 数量较高
- README 显示每 6 小时更新一次订阅
- 公开订阅链接仍可访问

### 实测结果

❌ 不推荐作为主要方案

测试情况：

- 订阅链接可以获取
- Clash Verge 可以成功拉取配置
- 节点大量超时
- 部分节点显示存活但无法建立连接
- 可用节点比例极低
- 高峰时段基本不可用

### 原因分析

目前绝大多数节点来自公开收集池：

- 被大量用户共享
- IP 很快被封锁
- 节点生命周期短

因此：

> GitHub 仓库是活的，不代表节点是活的。

# 2026年的现实情况

经过近几年持续封锁后：

## 免费公开节点

现状：

- 存活时间越来越短
- 被共享后迅速失效
- GitHub节点池大量依赖互相搬运

常见现象：

- README显示更新
- Clash成功订阅
- 实际测速全部超时

即：

"有链接 ≠ 有节点"

"有节点 ≠ 能连接"

---

## Clash Verge 和 v2rayN 本身没有问题

很多用户误以为：

- Clash Verge失效了
- v2rayN失效了

实际上：

客户端通常工作正常。

问题主要来自：

- 节点被封
- IP被污染
- 订阅源失效
- TLS指纹被识别
- 服务端关闭
